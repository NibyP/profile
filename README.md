# Portfolio Landing Page (Next.js)

This repository contains a ready-to-run Next.js landing page template for a personal portfolio website.

## Sections included
- Name
- Role
- Skills
- Experience
- Projects
- Tools
- AI Tools

## Run locally
```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Customize
Update the content arrays in `app/page.tsx` to replace placeholder values with your own details.
